1. 課前暖身：電流是什麼？

電流在電路中的運作，可類比為水流系統：

水流系統

抽水馬達 (推力) → 水管 (通道) → 水車 (做功) → 窄管 (限制流速)

電路系統

電源 (電壓) → 導線 (電流通道) → LED (發光工作) → 電阻器 (限流)

4. 三用電表與串並聯規律

[測量守則] 量電壓用「並聯」，量電流用「串聯」。
[重要警告] 測量電阻（Ω）前，必須先關閉電源開關。

理論公式

串聯 (手牽手)：
R總 = R1 + R2
並聯 (肩並肩)：
1/R總 = 1/R1 + 1/R2
